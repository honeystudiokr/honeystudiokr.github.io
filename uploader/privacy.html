개인정보처리방침 (Privacy Policy)

시행일 2026년 10월 10일 · Effective October 10, 2026 · 운영: Honey Studio

1. 대상 (Scope)

서윤 업로더는 Honey Studio 운영자 본인만 사용하는 내부용 도구입니다. 운영자 외의 사용자를 받지 않으며, 다른 사람의 개인정보를 수집하지 않습니다.
This app is used only by the operator of Honey Studio. It does not accept other users and does not collect anyone else's personal data.

2. YouTube API 서비스 사용 (Use of YouTube API Services)

This app uses YouTube API Services. 이 앱은 YouTube API 서비스를 사용하며, 이 앱을 사용하면 YouTube 서비스 약관 (YouTube Terms of Service)에 동의하는 것으로 봅니다.
Google 개인정보처리방침 (Google Privacy Policy): https://policies.google.com/privacy

3. 사용하는 Google 사용자 데이터 (Google user data accessed)

운영자가 직접 승인한 경우에만 YouTube Data API로 운영자 소유 채널의 정보(채널 이름, 영상 목록·처리 상태)에 접근하고, 영상·썸네일 업로드와 제목·설명·태그·재생목록·공개 설정을 변경합니다.
With the operator's own consent, the app uses the YouTube Data API to read the operator's channel information (channel name, video list and processing status) and to upload and manage videos, thumbnails, titles, descriptions, tags, playlists and privacy settings on the operator's own channels.

4. 보관과 공유 (Storage and sharing)

인증 토큰은 운영자의 컴퓨터에만, 운영자 계정만 읽을 수 있는 파일로 저장되며 외부 서버로 전송하지 않습니다. 제3자에게 판매·공유·전송하지 않고, Google 사용자 데이터를 광고나 다른 목적에 쓰지 않습니다.
OAuth tokens are stored only on the operator's own computer, in files readable only by the operator's account, and are never sent to any external server. Google user data is never sold, shared or transferred to third parties and is not used for advertising or any other purpose.

5. 삭제와 권한 철회 (Deletion and revoking access)

운영자는 언제든 Google 보안 설정 (Google security settings)의 권한 페이지에서 이 앱의 접근을 철회할 수 있으며, 철회하면 저장된 토큰을 삭제합니다.
Access can be revoked at any time via https://security.google.com/settings/security/permissions; stored tokens are then deleted from the operator's computer.

6. Google API 서비스 사용자 데이터 정책 (Google API Services User Data Policy)

이 앱의 Google API 사용은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.
The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
