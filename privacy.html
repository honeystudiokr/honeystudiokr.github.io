개인정보처리방침 (Privacy Policy)

시행일 2026년 10월 10일 · Effective October 10, 2026

1. 이 웹사이트

이 웹사이트는 회원 가입·결제·쿠키 추적·방문자 분석을 하지 않으며 방문자의 개인정보를 수집하지 않습니다. 문의 메일을 보내신 경우 답장 목적에만 메일 주소와 내용을 사용하고, 목적이 끝나면 지체 없이 삭제합니다.
This website has no sign-up, payments, tracking cookies or analytics and collects no personal data from visitors. If you email us, your address and message are used only to reply and are deleted afterwards.

2. 내부 업로드 도구 (Seoyun Uploader / 서윤 업로더)

Honey Studio는 자체 채널에 영상을 올리기 위한 내부 도구를 사용합니다. 이 도구는 운영자 본인만 사용하며, 운영자가 직접 승인한 경우에만 YouTube API 서비스로 운영자 소유 채널의 정보(채널 이름·영상 목록)에 접근하고 영상·썸네일 업로드와 제목·설명·공개 설정을 관리합니다. 다른 사람의 계정이나 시청자 데이터에는 접근하지 않습니다.
Honey Studio uses an internal tool, used only by its operator, that accesses YouTube API Services with the operator's own consent to upload and manage videos on channels the operator owns. It does not access other users' accounts or any viewer data.

이 도구는 YouTube API Services를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. This tool uses YouTube API Services.

3. 보관·공유·삭제

인증 토큰은 운영자 컴퓨터에만 운영자 계정만 읽을 수 있는 파일로 보관하며, 제3자에게 판매·공유·전송하지 않고 광고 등 다른 목적에 쓰지 않습니다. 권한은 언제든 Google 계정 권한 페이지에서 철회할 수 있고, 철회 시 저장된 토큰을 삭제합니다.
Tokens are kept only on the operator's computer, never sold or shared, and deleted when access is revoked.

4. Google API 사용자 데이터 정책

Google API 사용은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.
